Denial 的参考桌面是嵌入合成器的 Flutter 桌面外壳。它提供应用启动器、仪表板、概览、
系统栏、剪贴板、通知、锁屏和设置。

## 桌面界面

- **应用**是一个可搜索的启动器。轻按并松开 `Super`，或将指针移入所配置的屏幕边缘触发区。
- **仪表板**可以快速访问壁纸选择、应用音量、蓝牙、电源模式和设置，也可以从屏幕边缘触发。
- **概览**显示当前桌面及其窗口。按 `Super+A` 打开。
- **系统栏**显示时钟、CPU 和受支持 GPU 的活动，以及活跃的 MPRIS 媒体。最大化窗口会避开
  系统栏，全屏窗口则会覆盖它。

默认情况下，启动器和仪表板从桌面左侧展开。可以在设置中更改它们的边缘、大小、位置和
关闭延迟。

> [!NOTE]
> 目前，受管理的 X11/Xwayland 窗口始终使用 Denial 的边框、圆角和阴影，即使应用要求
> 隐藏它们也是如此。这可以规避 X11 窗口最小化时一条已知的 Impeller 模糊和阴影损坏
> 路径。类似弹出窗口和 override-redirect 的 X11 表面仍然没有装饰。

## 全局快捷键

原生快捷键会在应用收到键盘或鼠标事件之前处理。

| 快捷键 | 操作 |
| --- | --- |
| 轻按 `Super` | 打开应用启动器 |
| `Super+A` | 打开概览 |
| `Super+Tab` | 切换窗口；重复按 `Tab`，然后松开 `Super` 完成选择 |
| `Super+M` | 最小化焦点窗口 |
| `Super+Up` | 切换最大化状态 |
| `Super+Shift+Up` | 切换垂直最大化 |
| `Super+F` | 切换全屏 |
| `Super+K` | 关闭焦点窗口 |
| `Super+V` | 打开剪贴板历史 |
| `Super+L` | 锁定会话 |
| `Super+Escape` | 释放被捕获或约束的指针 |
| `Super` + 按住左键拖动 | 移动窗口 |
| `Super` + 按住右键拖动 | 调整窗口大小 |
| 调高、调低音量或静音 | 更改默认音频输出 |
| `Super` + 调高或调低音量 | 更改指针所在显示器的亮度 |
| `Ctrl+Alt+Backspace` | 立即结束合成器会话 |

> [!CAUTION]
> `Ctrl+Alt+Backspace` 是紧急退出方式，尚未保存的应用内容可能会丢失。

## 剪贴板历史

按 `Super+V` 打开剪贴板历史。Denial 会记录原生 Wayland 和 Xwayland 应用的剪贴板活动，
可以保留文本、图像、文件以及其他公布的表示形式。

在剪贴板面板中可以：

- 搜索并激活项目；
- 固定需要保留的项目；
- 删除单个项目或清空历史；
- 暂停收集新的历史记录；
- 将项目拖入应用。

剪贴板历史属于会话界面数据。复制密码、令牌或私密文件时，请将它视为敏感信息。

## 通知与媒体

Denial 实现了标准桌面通知服务。通知会显示在桌面外壳中，并保留在通知中心，直到过期或
被关闭。安静模式可以抑制打扰，也可以限制锁屏预览来保护隐私。

提供 MPRIS 接口的应用会出现在系统栏中。媒体弹窗提供上一首、播放或暂停、下一首控制，
并显示可用的标题、艺术家、专辑和封面信息。

## 锁定与结束会话

`Super+L` 打开原生锁屏。身份验证使用 PAM 并始终留在合成器内部；需要时可以使用屏幕键盘。

会话菜单可以锁定、注销、挂起、休眠、重启或关机。系统操作通过 `systemd-logind` 发送，
因此活跃的抑制器或 polkit 策略可能要求确认或阻止操作。
