Denial 的参考桌面是嵌入合成器的 Flutter 桌面外壳。它提供启动器、仪表板、概览、系统栏、
剪贴板、通知、锁屏、工作区和窗口布局。Settings 是独立的 Wayland 应用，因此修改偏好
不会给合成器的 Flutter 帧增加工作量。

## 桌面界面

- **应用程序**是支持键盘导航的可搜索启动器。轻按并松开 `Super`，或把指针移入配置的
  边缘触发区即可打开。
- **仪表板**提供壁纸选择、输出与应用音量、蓝牙、电源模式和 Settings，也可从边缘打开。
- **概览**显示当前工作区中的窗口。按 `Super+A` 或在触控板上三指向上轻扫即可打开。
- **系统栏**显示时钟、系统活动、MPRIS 媒体、通知、StatusNotifier/AppIndicator 项目以及
  传统 XEmbed 托盘图标。每个选中的显示器都有独立系统栏。
- **Settings** 是普通的 Denial 管理 Wayland 窗口，可从启动器、仪表板、移动主屏或
  自定义快捷键启动。

启动器、仪表板、通知、HUD 和系统栏的位置与尺寸都可在 Settings 中调整。最大化窗口会
避开系统栏和配置的边距；全屏窗口会覆盖它们。

## 窗口布局与工作区

在 **Settings → 桌面布局** 中选择窗口布局：

- **堆叠**允许窗口互相重叠，并保留自由摆放的几何位置。
- **平铺**使用动态 dwindle 树。方向焦点、交换、边缘调整尺寸和拖动预览仍由合成器处理；
  瞬态窗口保持浮动。
- **滚动**把窗口排列成横向的全高列。焦点跟随活动列，触控板横向移动可通过速度感知的
  回弹移动整条窗口带。

切回堆叠布局时会恢复保存的堆叠几何。当前布局全局生效，但每个显示器本地工作区都分别
保留窗口顺序、分割尺寸和滚动视口。

工作区可选，并按显示器独立切换；一个显示器切换时不会移动其他显示器。工作区数量以及
水平或垂直过渡方向都可配置。最小化窗口在其显示器的所有工作区中都可恢复。

## 快捷键

合成器会在应用收到按键或手势前处理快捷键。**Settings → 快捷键** 可以添加、编辑或
删除绑定，目标可以是 Denial 操作、已安装的桌面应用、带字面参数的程序或 Shell 命令。
Denial 会先验证冲突，再保存由原生端管理的 `~/.config/denial/shortcuts.json`。

当前默认项包括：

| 快捷键 | 操作 |
| --- | --- |
| 轻按 `Super` | 打开应用程序 |
| `Super+A` / 三指向上轻扫 | 打开概览 |
| `Super+Tab` / 三指向左或右轻扫 | 切换窗口 |
| `Super+M` / `Super+Shift+M` | 最小化焦点窗口 / 所有窗口 |
| `Super+W` | 切换最大化状态 |
| `Super+Shift+Up` | 切换垂直最大化 |
| `Super+F` | 切换全屏 |
| `Super+K` | 关闭焦点窗口 |
| `Super+Left/Right/Up/Down` | 聚焦对应方向的窗口 |
| `Super+Ctrl+Left/Right/Up/Down` | 向对应方向交换受管窗口 |
| `Super+Alt+Left/Right` | 切换到上一个或下一个工作区 |
| `Super+Alt+Shift+Left/Right` | 把焦点窗口移到相邻工作区 |
| `Super+1` … `Super+9` | 直接切换到指定工作区 |
| `Super+Shift+1` … `Super+Shift+9` | 把焦点窗口移到指定工作区 |
| 四指轻扫 | 沿配置的过渡轴切换工作区 |
| `Super+V` | 打开剪贴板历史 |
| `Super+Shift+S` | 选择并捕获屏幕区域 |
| `Super+L` | 锁定会话 |
| `Super+Space` / `Super+Shift+Space` | 选择下一个 / 上一个键盘布局 |
| `Super+Escape` | 释放被捕获或约束的指针 |
| `Super` + 左键拖动 | 移动窗口 |
| `Super` + 右键拖动 | 调整窗口大小 |
| 音量增减或静音键 | 调整默认音频输出 |
| 亮度键或 `Super` + 音量增减键 | 调整指针所在显示器的亮度 |
| `Ctrl+Alt+Backspace` | 立即结束合成器会话 |

引入方向布局导航后，最大化快捷键从 `Super+Up` 改为 `Super+W`；已有快捷键文件会自动
迁移。**切换置顶**和**打开仪表板**是可选操作，但没有默认绑定。

> [!CAUTION]
> `Ctrl+Alt+Backspace` 是紧急退出方式，尚未保存的应用内容可能会丢失。

## 剪贴板、通知与媒体

按 `Super+V` 打开剪贴板历史。Denial 会记录原生 Wayland 和 Xwayland 的剪贴板活动，
并显示可搜索的文本、图像和文件卡片。项目可激活、固定、删除、全部清除、暂停记录，或
拖入应用。会话锁定时内容会被隐藏，但仍应把历史记录视为敏感数据。

通知会显示在桌面外壳中，并保留在通知历史中直到过期或关闭。激活通知可以唤起其已有
窗口。免打扰会抑制普通横幅，但关键警报仍可显示；锁屏预览可选择完整内容、仅应用名称
或完全隐藏。

提供 MPRIS 的应用会出现在系统栏中。媒体弹窗提供元数据、封面以及上一首、播放/暂停、
下一首操作。托盘项目也可显示应用提供的菜单并接收指针操作。

## 触控与移动桌面外壳

普通窗口保留一组由合成器处理的直接触控手势：从顶部 48 个逻辑像素拖动可移动窗口，
双指捏合可围绕中心调整大小，从顶部区域双指向下轻扫可最小化，三个触点同时按下可关闭。
手势一旦被识别，Denial 会取消应用先前收到的触控序列。

显式选择的移动桌面外壳提供分页主屏、最近应用、通知历史、快捷设置、状态栏、移动壁纸
控制、屏幕键盘、旋转控制和边缘手势。蜂窝网络状态、移动数据、SIM PIN、指纹显示、
唤醒手势和触觉反馈只会在相应硬件与系统服务可用时出现。公开软件包仍面向 x86-64 PC；
移动设备目前使用架构匹配的源码构建。

## 锁定与结束会话

`Super+L` 会关闭原生安全门并显示 Flutter 锁屏。密码认证使用 PAM。当 fprintd 已安装且
用户已录入指纹时，锁定期间也会自动开始验证；密码解锁始终并行可用。指纹录入需要先在
Settings 中通过一次独立的 sudo 密码检查。

会话菜单可以锁定、注销、挂起、休眠、重启或关机。系统操作通过系统会话服务执行，并
遵守抑制器和授权策略。电源页面还可分别设置空闲锁定、关闭显示器和自动挂起期限，并选择
可用的 Linux 挂起模式。
