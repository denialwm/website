在 Denial 中，Flutter 既不是客户端窗口，也不是覆盖层。引擎通过原生 Embedder API 嵌入，
Dart 桌面外壳运行在 `deniald` 内部。Rust 和 Flutter 在同一个桌面场景上协作，同时把
原生资源留在 Rust 一侧。

## 职责

Rust 和 Smithay 负责：

- Wayland 显示、协议、Xwayland 和客户端缓冲区；
- 输入设备、焦点、抓取和原生快捷键；
- DRM 设备、输出验证、KMS 显示和页面翻转；
- 文件描述符以及原生 Wayland、EGL、GBM 和 KMS 资源的生命周期。

Flutter 负责：

- 窗口布局和可见的桌面策略；
- 启动器、仪表板、概览、系统栏、设置和锁屏；
- 动画、手势行为和桌面外壳命中区域；
- 将应用纹理合成到桌面中。

这种划分使桌面外壳能够快速变化，又不必把不安全句柄或特权显示操作移入 Dart。

## 帧路径

Wayland 客户端缓冲区会作为外部纹理导入。Flutter 将这些纹理与桌面外壳界面合成到覆盖
整个桌面的 XRGB8888 GBM 图集中。每个物理输出通过 KMS 扫描显示该图集中分配给自己的
矩形区域。

```text
Wayland 客户端 ──> Rust / Smithay ──> 外部纹理 ──> Flutter 场景
        输入 <──── 原生路由 <──── 桌面外壳命中区域 <──────┘

显示器 <────────────── DRM / KMS <────────────── 共享 GBM 图集
```

显示时序与真实的输出帧周期绑定。因此，捕获请求和连续录制会随所选输出推进，而不会让
事件循环空转。

### 逻辑与物理缩放

桌面、输出、窗口和结构化光标坐标都保持为逻辑坐标。共享图集按最大活动输出缩放值以
物理分辨率分配，Flutter 也会收到同一个值作为设备像素比。这样，桌面外壳只需布局一个
逻辑桌面，同时以图集分辨率清晰栅格化；Denial 不会放大 Flutter 已经完成的图像。

原生 Wayland 表面会收到当前所属输出的精确首选缩放值。Xwayland 则使用最大输出缩放值
向上取整后的整数，作为整个会话共用的缩放，并配合对应的 DPI 提示，因为单个 X 服务器
无法为不同输出上的窗口分别缩放。

## 合成器边界上的 Impeller

Impeller GLES 是 Denial 的默认 Flutter 渲染器。这不仅仅是启用 Flutter 应用层的 Impeller
开关：Denial 渲染到由合成器拥有的轮换 GBM 帧缓冲池，而不是由另一个桌面提供的窗口。
锁定版本的 Denial Flutter 分支把 Impeller 直接集成到了这条图集路径中。

该集成会显示 Rust 主机选择的准确 FBO，在没有可用图集目标时安全结束帧，在轮换缓冲区
之间保留部分损伤，并让导入的 Wayland 纹理存活到原生 GPU 栅栏完成。合成器拥有的目标
还正确处理了打包的深度/模板存储和背景滤镜行为。

最终得到的是一幅由 Impeller 渲染、从 Flutter 直接进入 KMS 扫描图集的场景。Skia/Ganesh
仍被编译到同一代固定引擎中作为兼容性后备，不需要单独的引擎软件包。

## 原生—桌面外壳协议

合成器与桌面外壳通过有界、带版本的 FlatBuffers 协议通信。Dart 接收不可变元数据和数字
资源标识；它不拥有文件描述符或原生句柄，也不会启动辅助进程。

Flutter 会把交互区域发布回 Rust。原生输入路由随后可以判断事件属于桌面外壳、Wayland
表面、移动或调整大小抓取，还是合成器快捷键。

外部工具使用另一个带版本的 Unix 控制套接字。合成器会验证每个请求，并把接受的工作
排入其事件循环。

## Bundle 兼容性

`denial`、它的 Flutter 引擎和编译后的桌面外壳共同组成一个经过测试的版本代。Arch 软件包
要求精确匹配的引擎软件包。替换的桌面外壳必须使用匹配的原生协议，并应被视为受信任的
会话代码。

当前图集实现会拒绝任何超过 16,384 像素的桌面轴，或超过 1 GiB 的缓冲池。不支持的布局
会明确失败，而不会被静默裁切。
