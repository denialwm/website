Droidloom

Android apps as Wayland windows.

Droidloom is a companion open-source project: it runs Android apps and games as native windows on a Linux Wayland session. It pairs well with Denial Mobile ports and has a desktop preview of its own.

Alongside Denial

Where it helps.

01

On Denial Mobile

After Linux is ported to a supported phone or tablet, Droidloom can keep Android apps available next to Denial.

02

Desktop preview

The public preview targets x86_64 Arch Linux and Omarchy with AMD or Intel graphics. NVIDIA rendering is not validated yet.

03

Games

Arknights: Endfield runs through Droidloom. We don’t publish benchmark claims here.

Install

Droidloom preview

The preview targets x86_64 Arch Linux and Omarchy, with AMD or Intel graphics. NVIDIA rendering is not validated. Startup is manual. Follow the upstream install guide.
